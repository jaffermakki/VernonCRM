SMS (Twilio)

Paste this into Twilio Console → Phone Numbers → your number → Messaging → A MESSAGE COMES IN → Webhook, method HTTP POST. Once set, customer replies to receipts/repair-ready texts show up in that customer's page here, instead of going to a phone nobody's watching.

Daily Owner Digest

A nightly email summarizing revenue, repairs opened/closed, low stock, and cash-up status. Requires email to be configured above (either method).

Security Question

An extra checkpoint before any staff PIN can be changed — the person changing a PIN must know the answer, not just have Owner/Manager access. {% if settings.get('security_answer_hash') %}✓ Currently set.{% else %}Not set yet — PIN changes have no extra verification.{% endif %}

Not case-sensitive. Only the question is visible to managers — the answer is stored hashed and never shown back, even to you.

Send Test Email

Sends a simple test message to confirm your SMTP settings actually deliver — do this before relying on receipts or the daily digest.

Send Test Digest

Sends today's digest right now, using whatever's currently saved — handy for checking it works before relying on the nightly schedule.

Data Export

Your data lives in one SQLite file (crm.db) — the simplest backup is copying that file. These exports are for spreadsheets, accounting, or moving data elsewhere.
